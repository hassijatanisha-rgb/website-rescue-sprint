# Fictional page audit

Scope: one page, five agreed defects. This is a demonstration of the Website Rescue Sprint, not a real client audit.

| Defect | Starting state | Repair | Verification |
|---|---|---|---|
| 1. Unclear first action | Three equal calls to action and generic heading | One primary availability action and one secondary rates link | Primary action appears once in the hero and remains visible in the header |
| 2. Weak mobile layout | Fixed-width content and horizontally scrolling room cards | Fluid grid, wrapping navigation and breakpoint-specific spacing | No intended horizontal overflow at 320px and above |
| 3. Contact reliability | Email link contains a leading space; phone is plain text | Valid `mailto:` and `tel:` links with readable labels | Link targets are syntactically valid and keyboard reachable |
| 4. Low contrast and missing focus | Pale text on white; links rely on color; no visible focus | Tested high-contrast palette, underlined inline links and `:focus-visible` rings | Focus indicator is present on links and buttons |
| 5. Scanning friction | Long undifferentiated paragraphs and inconsistent prices | Short sections, rate table and compact trust details | Heading order is linear and rates use one consistent format |

## Honest boundary

This sample demonstrates frontend judgment and implementation only. It does not prove commercial conversion gains, production hosting, analytics, a CMS, payment integration or client results.
